JavaScript DOM & Web APIs

Comprehensive Notes for Full-Stack Development Preparation

1. Introduction to the DOM (Document Object Model)

The DOM is a programming interface for web documents. It represents the page so that programs can change the document structure, style, and content. It views an HTML document as a tree of nodes (where every HTML tag is a node).

Key Selectors:

  • document.getElementById("idName"): Returns a single element.
  • document.getElementsByClassName("className"): Returns an HTMLCollection (live list).
  • document.querySelector("selector"): Returns the first element matching a CSS selector.
  • document.querySelectorAll("selector"): Returns a NodeList (static list) of all matches.
Interview Gotcha: getElementsByClassName returns a live HTMLCollection, meaning if the DOM changes, the collection updates. querySelectorAll returns a static NodeList, which does not update dynamically. 
let mainHeading = document.querySelector("h1");
console.log(mainHeading);

2. DOM Manipulation: Modifying Content

Once selected, you can change the content inside an element.

  • innerText: Shows visible text only, respects CSS (ignores hidden text).
  • textContent: Shows all text content, including hidden text. Faster than innerText.
  • innerHTML: Gets or sets the HTML markup. Parses HTML tags.
Warning: Be careful with innerHTML when using user input, as it exposes your site to Cross-Site Scripting (XSS) attacks. Use textContent for pure text. 
let title = document.querySelector("h1");
title.textContent = "Welcome back!"; // Safe text update
title.innerHTML = "Welcome <span>back</span>!"; // Parses tags

3. Attribute & Class Manipulation

Attributes:

  • getAttribute("attrName"): Reads an attribute.
  • setAttribute("attrName", "value"): Changes or adds an attribute.

Classes (classList):

  • element.classList.add("class") / .remove("class"): Adds or removes a class.
  • element.classList.toggle("class"): Adds if missing, removes if present (great for UI toggles).
let link = document.querySelector("a");
link.setAttribute("href", "https://google.com");

let box = document.querySelector(".box");
box.classList.toggle("dark-mode");

4. Dynamic DOM Manipulation

Creating elements in JavaScript and injecting them into the HTML document.

  • document.createElement("tagName"): Creates an empty node in memory.
  • element.appendChild(newNode): Adds node as the last child.
  • element.prepend(newNode): Adds node as the first child.
  • element.style.property: Edits inline CSS (use camelCase, e.g., backgroundColor).
let newBtn = document.createElement("button");
newBtn.textContent = "Click Me";
newBtn.style.backgroundColor = "blue";
document.body.appendChild(newBtn);

5. Events and Event Handling

Listening for user interactions like clicks, typing, and mouse movements.

let btn = document.querySelector("button");
btn.addEventListener("click", function(event) {
    console.log("Button clicked!");
    console.log(event.target); // The exact element that was clicked
});

6. Event Bubbling & Delegation (Advanced/Important)

Event Bubbling: When an event happens on an element, it first runs the handlers on it, then on its parent, then all the way up on other ancestors.

Event Delegation: Instead of adding an event listener to 100 individual list items, you add ONE listener to their parent <ul> and use event.target to figure out which <li> was actually clicked. This saves massive amounts of memory.

  • event.stopPropagation(): Stops the event from bubbling up to parent elements.
// Event Delegation Example
let ul = document.querySelector("ul");
ul.addEventListener("click", function(event) {
    if(event.target.tagName === "LI") {
        console.log("You clicked a list item: " + event.target.innerText);
    }
});

7. Forms and Form Validation

Handling user inputs and form submissions safely.

Crucial: Use event.preventDefault() inside a submit event listener to stop the browser from refreshing the page and wiping out your state. 
let form = document.querySelector("form");
form.addEventListener("submit", function(event) {
    event.preventDefault(); // Prevents page reload
    
    let inputVal = document.querySelector("input").value;
    if (inputVal === "") {
        console.log("Error: Input cannot be empty");
    }
});

8. Timers and Intervals

Executing code after a delay, or executing code continuously at a set interval.

  • setTimeout(callback, ms): Runs code ONCE after ms milliseconds.
  • setInterval(callback, ms): Runs code REPEATEDLY every ms milliseconds.
  • clearTimeout(id) / clearInterval(id): Stops the timer.
// Runs once after 2 seconds
setTimeout(function() {
    console.log("2 seconds have passed!");
}, 2000);

// Runs every 1 second
let intervalId = setInterval(function() {
    console.log("Tick...");
}, 1000);

// Stop the interval after 5 seconds
setTimeout(function() {
    clearInterval(intervalId);
}, 5000);

9. Asynchronous JS & Fetch API (Network Requests)

How JavaScript talks to servers, databases, and third-party APIs without reloading the page. Modern JS uses fetch() which returns a Promise.

A Promise represents the eventual completion (or failure) of an asynchronous operation.

// Using async/await (Modern approach)
async function getUserData() {
    try {
        // 1. Fetch data from an API
        let response = await fetch("https://jsonplaceholder.typicode.com/users/1");
        
        // 2. Convert response to JSON object
        let data = await response.json(); 
        
        console.log(data.name); 
    } catch (error) {
        console.error("Something went wrong:", error);
    }
}
getUserData();

10. Storage (localStorage & sessionStorage)

Saving data in the browser so it persists across page reloads.

  • localStorage: Persists until explicitly deleted.
  • sessionStorage: Deleted when the browser tab is closed.
Rule: Storage APIs can ONLY store Strings. To save an array or object, you must turn it into a string first using JSON.stringify(), and convert it back using JSON.parse(). 
let user = { name: "Akash", role: "Developer" };

// Save to storage
localStorage.setItem("currentUser", JSON.stringify(user));

// Retrieve from storage
let storedString = localStorage.getItem("currentUser");
let retrievedUser = JSON.parse(storedString);

console.log(retrievedUser.role); // Outputs: Developer
